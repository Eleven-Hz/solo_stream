============================================================
 Solo Stream — 사용 설명서
============================================================

게임 화면을 보고 AI가 채팅 반응을 만들어 주는 1인 방송 보조 오버레이입니다.
Python 설치 없이, 압축을 풀고 실행 파일만 누르면 됩니다.


------------------------------------------------------------
 0. 이 프로그램은 무엇을 위한 것인가
------------------------------------------------------------

방송을 처음 켜는 순간은 누구에게나 막막합니다. 아무도 없는 채팅창,
혼자 떠들어야 하는 어색함, 시청자 반응에 어떻게 응대할지에 대한 부담.
이 모든 것을 "실전"에서 처음 마주하면 쉽게 위축되기 마련입니다.

Solo Stream 은 그 첫걸음을 위한 연습 무대입니다.

실제 방송을 시작하기 전에, AI가 만들어 내는 시청자 채팅을 곁에 두고
게임을 플레이해 보세요. AI는 당신의 화면과 혼잣말을 보고 들으며,
마치 진짜 시청자처럼 반응합니다. 당신은 그 흐름 속에서

   · 카메라(화면) 앞에서 혼자 말하는 감각을 익히고,
   · 채팅에 자연스럽게 응답하는 호흡을 연습하며,
   · 나만의 방송 톤과 페이스를 부담 없이 다듬을 수 있습니다.

부담 없는 무대에서 충분히 적응한 뒤, 진짜 방송으로 나아가세요.
Solo Stream 은 그 도전의 리허설입니다.


------------------------------------------------------------
 1. 설치 (압축 풀기)
------------------------------------------------------------

1) 받은 ZIP 파일을 마우스 오른쪽 클릭 → "압축 풀기".
2) 풀린 "SoloStream" 폴더를 원하는 위치로 옮기세요.
   - 권장: 바탕화면, 문서 폴더 등 "쓰기 가능한" 위치.
   - 비권장: "C:\Program Files" 안. (권한 문제로 일부 동작이 막힐 수 있음)
3) 폴더 안 구조는 아래와 같습니다. 폴더 통째로 옮기세요.

   SoloStream\
     SoloStream.exe      ← 이 파일을 실행
     _internal\          ← 프로그램 구성 파일 (지우거나 옮기지 마세요)
     사용설명.txt        ← 지금 이 문서


------------------------------------------------------------
 2. 처음 실행 — Windows 보안 경고(SmartScreen)
------------------------------------------------------------

처음 SoloStream.exe 를 실행하면 파란 화면으로 이런 경고가 뜰 수 있습니다.

   "Windows의 PC 보호  —  Microsoft Defender SmartScreen이
    인식할 수 없는 앱의 시작을 차단했습니다."

이는 바이러스라서가 아니라, 이 프로그램에 "코드 서명 인증서"가 없기
때문입니다(개인 제작 프로그램에서 흔함). 아래처럼 실행하세요.

   1) "추가 정보" 글자를 클릭.
   2) 아래에 나타나는 "실행" 버튼 클릭.

백신이 막는 경우에도 같은 이유(오탐)일 수 있습니다. 신뢰하신다면
백신의 "허용/예외" 목록에 SoloStream 폴더를 추가하세요.


------------------------------------------------------------
 3. 첫 실행 — API 키 입력 (필수)
------------------------------------------------------------

이 프로그램은 AI(Gemini·OpenAI·Claude)를 사용합니다. 셋 중
하나 이상의 본인 API 키가 필요합니다. 고른 모델의 키가 없으면
가지고 있는 키로 자동으로 대체해서 동작합니다.

  ★ 처음이면 Gemini 를 권장합니다 — 무료 등급으로 시작할 수 있습니다
    (신용카드 등록 불필요).
    - 기본 채팅 모델(gemini-2.5-flash-lite) 무료 한도(2026년 기준):
      하루 약 1,500회 요청 / 분당 30회.
    - 이 프로그램은 화면이 바뀔 때만 캡처해 요청을 아끼므로, 보통의
      플레이 세션이면 무료 한도 안에서 충분히 사용할 수 있습니다.
    - 한도가 자주 부족하면 Google AI Studio에서 유료(종량제)로
      올릴 수 있습니다.
  ★ OpenAI 키가 있으면 채팅(gpt-6-luna)과 음성 인식(gpt-transcribe)
    품질이 더 좋습니다(유료·종량제).
    설정 '사용량' 탭에서 실제 쓴 금액을 실시간으로 볼 수 있습니다.

[3-1] Gemini API 키 발급
   1) 아래 주소를 브라우저에서 엽니다.
        https://aistudio.google.com/apikey
   2) Google 계정으로 로그인.
   3) "Create API key" (API 키 만들기) 클릭.
   4) 생성된 키(영문/숫자 문자열)를 복사합니다.
      ※ 이 키는 비밀번호와 같습니다. 남에게 공유하지 마세요.
   (OpenAI 키: https://platform.openai.com/api-keys
    Claude 키: https://console.anthropic.com/settings/keys)

[3-2] 프로그램에 키 입력
   - 키가 없는 상태로 실행하면 설정 창의 'AI 모델 · 키' 화면이
     먼저 열립니다. (나중에는 '방송 준비'의 [키 관리] 버튼으로 이동)
   - 쓰려는 서비스 줄의 [추가]를 눌러 키를 붙여넣고 [저장].
   - 저장하면 아래쪽에 [지금 다시 시작] 버튼이 나타납니다. 누르면
     프로그램이 다시 켜지면서 AI·음성 기능이 활성화됩니다.

   참고
   - 음성 인식은 OpenAI 나 Gemini 키가 있어야 합니다
     (Claude 키만 있으면 음성 인식은 꺼집니다).
   - 게임 프로필 '자동 생성'은 Gemini 키가 있어야 합니다. 키가 없어도
     '프롬프트 복사'로 ChatGPT·Claude·Gemini 앱에서 무료로 만들 수
     있습니다(설정 '게임 · 프로필').

입력한 키는 본인 PC의 아래 위치에 저장됩니다(빌드에 포함되지 않음).
        %APPDATA%\SoloStream\.env.local


------------------------------------------------------------
 4. 기본 사용법
------------------------------------------------------------

- 프로그램을 켜면 화면 위에 반투명 채팅 오버레이가 뜹니다.
- 게임을 실행하면, 설정된 대상 창을 주기적으로 캡처해 AI가
  보고 채팅 반응을 생성합니다.
- 마이크가 켜져 있으면 혼잣말(한국어)을 인식해 반응에 반영합니다.

설정 창에서 바꿀 수 있는 항목:
   - 게임      : 캡처할 대상 창, 캡처 주기 등 (하단에 버전 정보 표시)
   - AI 모델   : 사용할 모델, API 키
   - 음성      : 마이크 입력 / 음성 인식 설정
   - 비용      : 현재 고른 모델과 사용량 가정으로 예상 비용을
                 미리 가늠해 보는 계산기 (실제 청구액과 다를 수 있음)


------------------------------------------------------------
 5. 내 데이터는 어디에 저장되나요
------------------------------------------------------------

설정·키·로그는 프로그램 폴더가 아니라 아래 사용자 폴더에 저장됩니다.
(프로그램을 다른 곳으로 옮겨도 설정이 유지됩니다.)

        %APPDATA%\SoloStream\

   ※ %APPDATA% 는 Windows가 자동으로 채워 주는 경로 변수입니다. 실제
     위치는 보통 다음과 같습니다(사용자 이름에 따라 달라집니다):
        C:\Users\<사용자이름>\AppData\Roaming\SoloStream\

   - config.local.yaml  내 설정값 (바꾼 값만 여기 저장 — UI 저장도 여기에)
   - .env.local         API 키
   - personas\          내 봇 파일을 두는 곳 (새 .yaml 추가)
   - game_profiles\     게임별 프로필 (자동 생성)
   - logs\              실행/채팅 로그

   ※ 기본값(번들의 config.yaml, personas\default_bots.yaml)은 프로그램
     폴더에 읽기전용으로 들어 있습니다. 직접 고치지 마세요 — 업데이트 때
     덮어써집니다. 바꿀 값은 위 config.local.yaml / 내 봇 파일에만 적으면
     기본값 위에 합쳐져 적용되고, 업데이트에도 그대로 유지됩니다.

여는 방법은 두 가지입니다.
   1) 설정 창 > 게임 탭 > "로그" 아래 [데이터 폴더 열기] 버튼을 누르면
      탐색기에서 위 폴더가 바로 열립니다. (가장 쉬움)
   2) 탐색기 주소창에  %APPDATA%\SoloStream  을 입력해도 됩니다.

프로그램을 완전히 삭제하려면: SoloStream 폴더와 위 사용자 폴더를
모두 지우면 됩니다.


------------------------------------------------------------
 5.5 심화 사용법 (직접 꾸미기)
------------------------------------------------------------

기본값만으로도 충분하지만, 두 가지를 직접 손보면 훨씬 내 방송에
맞는 분위기를 만들 수 있습니다. 둘 다 위 데이터 폴더
(%APPDATA%\SoloStream\) 안에서 작업합니다.

[5.5-1] 시청자(봇) 직접 만들기 — personas\

   AI 시청자들의 성격·말투는 YAML 파일로 정의됩니다. 기본 봇들은
   프로그램 폴더(읽기전용)의 default_bots.yaml 에 들어 있어요.

   ★ 핵심: 기본 봇(번들) + 데이터 폴더 personas\ 안의 내 *.yaml 파일을
     합쳐서 읽습니다. 그러니 기본 파일은 건드리지 말고, 데이터 폴더
     personas\ 에 새 파일을 만들어 내 봇을 추가하면 됩니다. (이렇게 하면
     업데이트로 기본 봇이 늘어나도 자동 반영되고, 내 봇도 그대로 유지됩니다.)

   따라하기:
     1) 데이터 폴더 > personas\ 폴더를 엽니다. (처음엔 비어 있습니다.)
        (설정 > 게임 탭 > [데이터 폴더 열기] 로 연 뒤 personas 로)
     2) 형식은 프로그램 폴더의 default_bots.yaml 을 메모장 등으로 열어
        참고합니다. (직접 고치진 말고 형식만 보세요.)
        - 파일 맨 위 주석에 각 항목(style, frequency, aliases,
          user_speech_weight 등)의 의미와, 기본 봇 수정/제외 방법이
          설명되어 있습니다.
     3) 새 파일(예: my_bots.yaml)을 만들고, 아래처럼 최소 형식을
        지켜 봇을 적습니다. (들여쓰기는 공백 2칸)

           bots:
             - name: "내가만든봇"
               style: "반말, 응원 위주, 짧게"
               emotion: "신남"
               relationship: "찐팬"
               frequency: "high"

     4) 저장 후 프로그램을 다시 켜면 새 봇이 시청자 풀에 합류합니다.

   주의:
     - 확장자는 반드시 .yaml, 인코딩은 UTF-8 로 저장하세요.
     - 들여쓰기에 탭(Tab)을 쓰면 안 됩니다(공백만). 형식이 깨지면
       그 파일의 봇은 무시될 수 있으니 default_bots.yaml 을
       그대로 베껴 시작하는 게 가장 안전합니다.
     - 기본 봇을 바꾸거나 빼고 싶을 땐(번들 파일을 고치지 말고) 내
       파일에서 처리합니다:
         · 수정: 기본 봇과 같은 name 으로 다시 적으면 그 봇을 덮어씁니다.
         · 제외: 같은 name 에 disabled: true 만 적으면 그 봇이 빠집니다.
         · 기본 봇 전체 끄기: 내 파일 맨 위에 disabled: true 를 적습니다.
       (자세한 건 default_bots.yaml 맨 위 주석 참고.)

[5.5-2] 게임 프로필 만들기 — 프로필이 없을 때

   게임 프로필은 "이 게임이 어떤 게임인지"를 AI에게 알려 줘서
   반응의 맥락을 잡아 줍니다. 목록에 내 게임이 없다면 직접
   만들 수 있습니다.

   따라하기:
     1) 게임을 실행해 둡니다.
     2) 설정 > 게임 탭 > "캡처 창"에서 게임 창을 선택하고
        [캡처 적용] 을 누릅니다.
     3) 아래 [선택 창 게임 프로필 재생성] 버튼을 누릅니다.
        - 선택한 창에 맞는 프로필이 없으면 새로 생성되고,
          있으면 다시 만들어 덮어씁니다.
     4) 생성이 끝나면 "게임 프로필" 목록에 추가됩니다. 골라서
        [프로필 적용] 을 누르면 즉시 반영됩니다.

   참고:
     - 만들어진 프로필은 데이터 폴더 > game_profiles\ 안에
       YAML 파일로 저장됩니다. 직접 열어 내용을 다듬어도 됩니다.
     - 프로필을 따로 안 만들어도 창 제목에서 게임 이름을 자동으로
       추정해 동작합니다. 프로필은 "더 정확한 반응"을 위한 선택
       사항입니다.


------------------------------------------------------------
 6. 문제 해결
------------------------------------------------------------

Q. 실행해도 아무 반응이 없어요.
   - 백신/SmartScreen이 막았는지 확인하세요(2번 항목).
   - _internal 폴더가 SoloStream.exe 옆에 그대로 있는지 확인하세요.

Q. AI가 반응을 안 해요 / "키가 없다"는 안내가 떠요.
   - API 키가 올바르게 저장됐는지(3번 항목) 확인하고,
     [지금 다시 시작]으로 재실행하세요.

Q. 캡처가 안 돼요.
   - 설정 > 게임 에서 "대상 창" 이름이 실제 게임 창과 맞는지
     확인하세요.

Q. 오류를 제보하고 싶어요.
   - %APPDATA%\SoloStream\logs\ 폴더의 최신 로그 파일을 함께
     보내주시면 원인 파악에 도움이 됩니다.
