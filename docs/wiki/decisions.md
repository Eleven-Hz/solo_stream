# 설계 결정과 이유

> 무엇을 했는지는 git log 에 있다. 여기는 **왜** 그렇게 했는지만, 날짜순으로 한 항목씩.

## 2026-10-15

- **반복 채팅의 진짜 원인은 소재 쏠림** — 예제 문장 재발화(0.2%)가 아니라 "렉" 같은 클리셰에 봇이 몰린 것(옛 로그 5.9%). 그래서 문장 중복 검사가 아니라 소재 단위로 억제(`src/chat/topic_guard.py`): 최근 과열 소재는 프롬프트로 피하게 하고, 한 라운드 같은 소재는 2명까지. 시뮬레이션 5.9% → 3.3%.
- **다른 시청자 명단(roster)을 넣으면 발언자 외 채팅도 드롭** — 명단을 넣자 LLM 이 batch 밖 봇 채팅까지 지어냄(라운드 13개). 프롬프트 금지만으론 불충분해 후처리로 막는다.
- **채팅 기본 = gpt-6-luna** — 같은 20라운드 A/B 에서 스트리머 말 반응이 가장 좋고 비용은 flash-lite 수준([실측](models-and-providers.md)). 화면 분석은 3장면 비교로는 근거 부족이라 gemini-2.5-flash 유지.
- **키는 셋 중 하나만 있으면 된다** — Gemini 필수는 처음에 Gemini 하나로 만들던 구조의 흔적이었다. 기능상 Gemini 전용은 프로필 자동 생성(구글 검색 그라운딩)뿐. 키가 없으면 앱을 멈추는 대신 있는 키로 대체하고 알린다.
- **키 없는 모델도 선택은 저장, 대신 행마다 경고** — 원복하면 사용자가 "왜 안 바뀌지?"가 되고, 기본 선택이 처음부터 키 없는 경우는 표시도 없었다.
- **게임 프로필은 구독 채팅 붙여넣기가 기본, 자동 생성은 버튼** — 자동 생성은 검색 6회(그라운딩 요금 + 503 중단 + 고유명사 오역). 사용자의 ChatGPT/Claude/Gemini 구독 검색이 더 깊고 비용 0. 사용자 방향: 유료 API 자동 호출보다 수동 경로 선호.
- **붙여넣기 파서는 관대하게** — 실제 웹검색 모델 답에서 항목 속 두 번째 콜론("예: …")이 YAML 을 통째로 깨뜨리고, 출처 링크가 붙어 왔다. 정식 YAML 실패 시 줄 단위로 읽고 출처를 지운다.
- **실제 사용량은 API 가 보고한 토큰으로** — 예상치는 채팅 입력을 1,500 으로 가정해 실제(5,800)의 1/4 이었다. 추정을 고치는 것보다 실측을 보여주는 게 정확하다.
- **분석 주기를 바꾸면 페이싱도 비례** — 채팅은 별도 타이머 없이 화면 분석 라운드마다 1회. 15초 기준으로 맞춘 채팅 표시 간격·소재 윈도우를 주기에 비례시켜, 주기를 줄여도 메시지가 다음 라운드와 겹치지 않고 소재 감지가 같은 '시간'을 본다. 한 발화는 최대 2라운드까지(짧은 주기에서 같은 말에 계속 반응하는 것 방지).
- **README 스크린샷은 위젯 렌더 + 가짜 데이터** — 원격 화면에서 화면 캡처가 잘렸고, 실제 키·경로가 찍히면 안 된다(`tests/ui/readme_shots.py`).
- **대화가 안 이어지는 원인은 모델이 아니라 구조** (실사용 36라운드 로그) — ① 채팅이 화면 분석 주기에만 생겨 말하고 10~20초 뒤 반응, ② 발화 있는 라운드에서도 5명 중 0~2명만 반응(인사 무시), ③ 과열 소재 회피가 지금 장소·상황(보스전 중 '보스')까지 막음, ④ 봇끼리 받아치기 0회, ⑤ 말버릇 반복("새벽두부 방송도…" 5회). 대응은 `src/chat/flow.py` + 발화 즉시 반응 라운드. [결과](evaluation.md#대화-흐름-개선-전후-2026-10-16)
- **확률·선정은 코드가, 프롬프트엔 '누가 무엇을'만** — '[타인 반응 빈도] 70~90%' 지시가 있어도 실제 받아치기는 0회였다. 받아칠 봇과 대상을 코드가 정해 지시하자 23회.
- **발화 즉시 반응은 채팅만, 화면은 재사용** — 화면 분석까지 다시 하면 비용·지연이 두 배. 화면은 15초 안에 크게 안 바뀐다. 채팅 비용은 약 1.9배(실측 $0.14→$0.26/h)라 설정에 끄는 스위치를 둔다.
- **CrossCode 프로필은 게임 데이터의 공식 한국어로** — 화면에 뜨는 글자와 이름이 같아야 화면 분석·채팅이 맞는다. 자동 생성 프로필엔 오역이 많았다(루키 하버, 분지 요새 …). 방법은 [game-profile-sources.md](game-profile-sources.md).
