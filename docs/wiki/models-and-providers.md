| 모델 | 메시지 | HP/SP 언급 | 평균 길이 | 입력/출력 토큰 | 지연 | 시간당 |
|------|------|------|------|------|------|------|
| gemini-2.5-flash-lite (이전 기본) | 96 | 9% | 13.4자 | ~5,600 / – | – | $0.15 |
| **gpt-6-luna (현재 기본)** | 90 | **2%** | 13.7자 | ~5,800 / 103 | 3.2초 | $0.15 |
| claude-haiku-5-5 | 90 | 3% | 17.5자 | **~9,800** / 180 | 1.8초 | $0.26 |
| gpt-5-nano | 79 | 18% | 16.9자 | ~5,900 / 152 | 1.9초 | $0.09 |

판단은 숫자가 아니라 **대화록을 읽고** 했다 — "스트리머 말에 반응하는가"가 핵심.
- **gpt-6-luna**: 발화 반응이 가장 많고 짧고 자연스럽다("레벨 높으면 경험치 1뿐이야? 😭"). 지연 3초대는 15초 주기에 문제없음.
- **claude-haiku-5-5**: 반응 좋고 정답도 가끔 냄. 다만 "15자 이내" 규칙을 자주 넘기고(40자), 비용이 1.7배.
  - 정정: 비교 당시 Haiku의 "바키 쿰"·"Bergen Village"·"Basin Keep"을 지어낸 지명으로 봤으나 **셋 다 실제 지역**이다(게임 데이터 확인).
- **gpt-5-nano**: "피 빵빵하네" 반복, 맥락 없는 말 → 탈락.
- 모든 모델이 화면이 바뀐 직후의 직접 질문("누구 집이었더라?")에는 답하지 못함 — 모델보다 프롬프트 과제.

프로필을 공식 데이터로 다시 쓴 뒤(2026-10-15) 채팅 입력은 ~5,000토큰으로 줄었다.

## provider API 특성 (코드에 반영된 것)

- **OpenAI 추론 끄기**: `reasoning.effort` 허용값이 모델마다 다르다 — gpt-6-luna는 `"none"`, gpt-5 계열은 `"minimal"`부터(`"none"` 거부), gpt-4.1·4o 계열은 reasoning 파라미터 자체가 없다. `OpenAIClient._create`가 거절되면 한 단계씩 내리고 모델별로 기억한다.
- **Claude 사고 끄기**: `thinking={"type":"disabled"}`. 5세대(claude-*-5…)는 `output_config.effort: "low"`도. `claude-haiku-4-5-20251001`은 4세대 — 정규식을 `claude-[a-z]+-5(-\d+)?$`로 좁힌 이유.
- **Claude 토크나이저**: 같은 한국어 프롬프트를 Gemini/OpenAI의 약 **1.7배** 토큰으로 센다(9,800 vs 5,800). 단가가 같아도 실제 비용은 1.7배. 예상 비용은 `token_mult`로 보정, 실제 사용량은 API가 센 값을 그대로 쓴다.
- **Gemini 사고 토큰**: `thoughts_token_count`는 출력 요금으로 청구 → 사용량 집계에서 출력에 합산.
- **OpenAI transcribe**: `response_format="text"`는 사용량을 안 돌려준다 → 보낸 오디오 길이(`len(pcm)/sr`)로 분당 과금 계산.
- **키 대체 순서**: 고른 provider 키가 없으면 `openai → gemini → claude` 순으로 있는 키의 기본 모델로 대체(`resolve_provider`). 키가 **있지만 무효**면 대체되지 않고 호출 오류가 난다.
- **웹 검색(고인물 봇, 2026-10-23)**: OpenAI 는 Responses `tools=[{"type":"web_search"}]` — `reasoning.effort:"none"` 과 같이 써도 검색함(출력에 `web_search_call` 1~2개). Gemini 는 `GoogleSearch` 그라운딩. 검색 결과가 입력 토큰으로 잡혀 호출당 **입력 약 9~11k 토큰**(gpt-6-luna 기준 토큰값 약 $0.001) + provider 의 검색 호출 요금(사용량 탭에는 미반영). 지연 4~8초(gpt-6-luna), 5~9초(gemini-2.5-flash).
  - 한국어로 묻고 프로필 없이 검색하면 답이 엉성했다("사파이어 산맥 = 벌레 천지", "가을의 추락" 같은 표기). **영어로 검색 + 프로필 전체를 배경으로** 주자 "감염된 디그모", "대나무 숲", "마룬 밸리" 등 프로필·위키와 맞는 답.
  - Gemini 는 답 앞에 영어 메모("The search results confirm…")를 붙이기도 함 → 한글이 든 첫 줄만 씀. gemini-2.5-flash-lite 는 답이 부정확("마름모 던전 다음엔 사원 던전").
  - OpenAI 는 답 끝에 출처 링크 `([site](url))` 를 붙임 → 후처리로 제거.
