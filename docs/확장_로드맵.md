# 확장 로드맵 (2026-10-26)

v0.4.1 기준으로 Phase 1·2 핵심(캡처 → Vision → 채팅 → 오버레이, STT, 호명, 감정, 흥분도, 대화 흐름)과 설치형 배포가 끝났다.
이 문서는 **그다음에 무엇을 어떤 순서로 붙일지**를 정한다. 진행 상태는 개발 현황판(`open-dashboard.bat`)의 '기능' 탭이 단일 기준이고,
이 문서는 각 기능의 설계 근거다.

- 원칙은 기획서와 같다: 새 SDK는 `src/ai/model_client.py` 한 곳, 설정은 `config.yaml` 단일 진실(스키마를 바꾸면 `main.py`·`ui/settings.py`·도메인 모듈을 함께), 한국어 톤.
- 비용 목표(월 $5, 상한 $10)를 넘기는 기능은 기본 꺼짐으로 둔다.
- 봇 정확성은 목표가 아니다(2026-10-23 결정). 확장도 **방송 같은 느낌과 대화 구조**를 늘리는 쪽으로 간다.

## 1단계 — 게임 이벤트에 채팅이 몰림

**지금 있는 것**
- `src/chat/hype.py`: 스트리머 발화 + 직전 봇 채팅의 강조어·ㅋㅋ·ㅠㅠ로 hype(0~1)·valence(±1)를 낸다. 임계값을 넘으면 delay를 좁히고 batch를 늘리고 `mood_hint`를 넣는다(`main.py` `HYPE_THRESHOLD`, 메아리 감쇠 포함).
- Vision 프롬프트에 `이벤트:` 줄(HP 위기·보스 등장·레벨업 등)이 있고, `main.py`가 `event_text`로 뽑아 **감정(`emotion.py`)에만** 쓴다.

**빈 곳**: 말없이 플레이할 때는 보스가 나와도 hype가 오르지 않는다. 화면 이벤트가 타이밍을 바꾸지 못한다.

**설계**
1. `compute_hype()`에 `event_text` 입력과 `event_weight`를 더한다. 이벤트 줄이 있으면 hype 기본값을 올리고, `emotion.event_valence()`를 재사용해 방향을 정한다(키워드 표를 두 벌 두지 않는다).
2. 이벤트 라운드 다음 1~2라운드는 **잔불**: hype를 단계적으로 낮춰 "우르르 → 잦아듦" 곡선을 만든다. 메아리 감쇠(`prev_round_hyped`)와 겹치지 않게 이벤트 출처를 따로 기억한다.
3. (선택) 이벤트가 잡히면 AI 프로세스가 캡처 프로세스에 `{"burst_capture": N}`을 보내 N초 동안 주기를 절반으로 줄인다. 비용이 늘기 때문에 기본 꺼짐.

**config**: `chat.event_hype_weight`(기본 0.6), `capture.burst_seconds`(기본 0 = 끔).

**검증**: `tests/replay/run.py`로 보스전이 있는 샘플 영상 전후 비교 — 이벤트 라운드 채팅 수·지연, 전체 호출 수. 결과는 `docs/wiki/evaluation.md` 방식대로 남긴다.

## 2단계 — 세션 간 기억

**목표**: "어제 그 보스에서 10번 죽었잖아ㅋㅋ", "오늘은 몇 시간 하세요?"처럼 봇이 지난 방송을 기억한다.

**설계**
1. 세션이 끝날 때(앱 종료·게임 변경) 그 세션의 라운드 로그에서 **방송 일지** 한 단락을 만든다: 게임, 시간, 주요 이벤트 3~5개, 스트리머가 한 말 중 인상적인 것, 많이 웃긴 순간. 채팅 모델 한 번 호출(세션당 1회라 비용 무시 수준).
2. 저장: 사용자 데이터 폴더 `sessions/<게임>/<날짜시각>.yaml`. `last_session.yaml`과 같은 `paths.user_data_dir()` 규칙을 따른다.
3. 다음 세션 시작 시 같은 게임의 최근 일지 2~3개를 프롬프트의 `[지난 방송]` 섹션으로 넣는다. 매 라운드 다 넣으면 토큰이 늘어나므로 **세션 첫 N라운드 + 호명·질문 라운드**에만 넣는다.
4. 페르소나에 `remembers: true`(기본 false)를 두어 단골 봇만 기억을 쓴다. 출첵러·고인물 같은 봇이 적임.

**config**: `memory.enabled`, `memory.keep_sessions`(기본 10), `memory.inject_rounds`(기본 5).

**열린 질문**: 일지를 사용자가 설정 창에서 보고 지울 수 있어야 하는가(사생활) — 기본은 "보기·지우기 버튼"을 둔다.

## 3단계 — 가짜 방송 경제

**목표**: 시청자 수, 후원(도네), 구독, 입장 알림 — 방송의 보상 루프.

**설계**
1. 새 모듈 `src/chat/economy.py`: 상태 `viewers`, `followers`, 세션 누적 후원. 라운드마다 hype·이벤트·스트리머 발화량으로 시청자 수를 천천히 움직인다(급등은 이벤트 직후만). 순수 함수 + 상태 dataclass로 두어 리플레이에서 재현 가능하게.
2. 후원 메시지는 **기존 채팅 생성 batch에 끼워** 만든다(별도 호출 없음): 이번 라운드에 후원이 뽑히면 프롬프트에 "봇 X가 N원 후원하며 한마디" 지시를 추가. 도네요정 같은 봇이 이미 있으므로 페르소나 `donor: true`로 확률을 높인다.
3. UI 메시지 타입 추가: `{"system": True, "type": "donation", ...}`, `{"system": True, "type": "viewers", ...}`. 오버레이 `_handle_message`에 분기 추가, 후원은 강조 스타일(테마 `ui/theme.py`의 색 토큰)로 표시.
4. 시청자 수는 오버레이 타이틀바에 작게(👁 123).

**config**: `economy.enabled`(기본 true), `economy.donation_rate`, `economy.base_viewers`.

**주의**: 숫자가 실제 돈처럼 보이지 않게 단위를 "치즈·별풍선" 같은 가상 화폐 이름으로 둔다(설정에서 이름 변경).

## 4단계 — OBS 브라우저 소스 위젯

**지금 있는 것**: `src/export/websocket.py` — 채팅을 `{"name","message"}` JSON으로 WebSocket 브로드캐스트(기본 꺼짐, `127.0.0.1:8765`).

**설계**
1. `src/export/widget.html` 한 장: WebSocket에 붙어 채팅을 투명 배경으로 그린다. OBS '브라우저 소스'에 `file:///…/widget.html?port=8765` 로 넣는다.
2. 3단계의 후원·시청자 메시지도 같은 소켓으로 내보내 위젯이 알림으로 띄운다.
3. 설정 창 '오버레이' 페이지에 "OBS 위젯 켜기 + 경로 복사" 버튼.

**검증**: 브라우저로 위젯을 열고 리플레이 실행 → 채팅 표시 확인(스크린샷).

## 5단계 — 상호작용 확장

| 기능 | 설계 요약 |
|------|-----------|
| 투표·예측 | 스트리머가 "투표! A냐 B냐"라고 말하면(STT) `flow.py`가 투표 라운드를 연다. 봇마다 성향대로 표를 던지고 오버레이에 막대로 표시, 30초 뒤 마감. 예측(성공/실패)은 다음 Vision 이벤트로 판정 |
| 미션·챌린지 | 봇이 가끔 미션을 건다("노힐로 깨보세요"). 미션 상태를 `economy.py`에 두고, 성공·실패는 Vision 이벤트로 판정 → 후원·반응 |
| 채팅 직접 입력 | 오버레이 하단 입력칸(단축키로 열기). 입력문을 STT 발화와 같은 경로(`stt_queue` 형태)로 넣어 호명·질문 처리를 그대로 탄다 |

## 6단계 — 봇 TTS · 하이라이트 클립

- **TTS**: 후원 메시지와 호명에 대한 답만 읽는다(전부 읽으면 시끄럽다). TTS SDK는 `src/tts/` 단일 진입점에 격리(모델 교체 주기 대비). 후보: OpenAI TTS, Gemini TTS, Windows SAPI(무료·로컬, 한국어 음성 있음 — 먼저 실측).
- **하이라이트 클립**: 캡처 프레임을 링 버퍼(최근 30초)에 두고, hype 임계값을 넘는 순간 앞뒤를 GIF/MP4로 저장. 세션 끝에 2단계 방송 일지와 함께 하이라이트 목록을 보여 준다. 메모리·디스크 사용량을 먼저 잰다.

## 보류 — 실제 방송 하이브리드

진짜 시청자 채팅(트위치·치지직)과 AI 봇을 섞는다. 대상이 "솔로 게이머"에서 "소규모 스트리머"로 바뀌고, 봇임을 밝히는 문제(플랫폼 정책·시청자 신뢰)가 생긴다. 하려면 먼저 사용자와 방향을 정한다.
